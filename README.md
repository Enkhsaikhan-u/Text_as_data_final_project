# How Conservative and Liberal News Media See Current Economic Condition: CNN vs Fox News

# Project Structure

- `analysis/analysis.ipynb` — main analysis notebook
- `output/` — figures and results
- `paper/CNN_vs_Fox.docx` — paper draft
- `paper/CNN_vs_Fox.pdf` — final paper
- `raw_data/cnn_articles.csv` — dataset of CNN articles
- `raw_data/cnn_links.csv` — scraped links for CNN
- `raw_data/foxnews_articles.csv` — dataset of Fox News articles
- `raw_data/foxnews_links.csv` — scraped links for Fox News
- `web_scraping/CNN_news_scraping.ipynb` — scraper notebook for CNN
- `web_scraping/Fox_news_scraping.ipynb` — scraper notebook for Fox News
